# Accepted design

This index records the Docker repository's accepted design choices and
tradeoffs. The area files carry the same weight as [AGENTS.md](../../AGENTS.md).

Read the relevant area files before proposing a change or recording a finding
or audit entry. Revisit a decision when the owner asks or new evidence changes
its documented impact. Record new owner-accepted decisions in the relevant area
file.

- [Images](accepted-design/images.md) covers mutable base image tags and
  runtime privileges.
- [Project workflow](accepted-design/project-workflow.md) covers image version
  ownership, the staged root image release, and repository scanning.
